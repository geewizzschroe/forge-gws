# Roguelike run mode content

Read by `forge.gamemodes.roguelike.RoguelikeContent`. See `design/roguelike-run-mode/DESIGN.md`.

This folder ships inside the app (it is a classpath resource of `forge-gui`), so it reaches Android
even though the app's `res` folder is replaced by downloaded assets. **`index.txt` must list every
file** (bundled files can't be listed at runtime); a test checks it. To edit content on a device,
copy this folder to `<Forge user data>/roguelike/content/`; when that folder exists it is used instead.

Jill's core and mono-blue starter, Lightning's starter and the enemy decks are designed content;
the rest is draft or sample content, there to make the run playable and testable.

- `config.json`: run numbers (`RunConfig`). Fields marked PLACEHOLDER in `RunConfig.java` stand in for open design questions.
  `cardScopeSets` and `cardScopeExceptions` set the card scope; `CardScopeTest` lists deck and pool cards outside it.
  `fullPoolSets` are the Full Pool's starting sets (the uncurated source of reward slots); `shopRemovalPrice` is the first price of the shop's card removal.
  `workshop*` set the Workshop node (artifact choices and prices, upgrade price, Base supplies and the ability they give).
  `floors` is the number of floors; `floorRules` has one entry per floor (the first is floor 1): an optional `layout` (else `mapLayout`), `enemyLifeBonus`, `enemyUpgrades` (how many of an enemy's creature cards get a random upgrade), and `enemyBaseScript`/`enemyBaseText`, an ability every enemy's Base gains on that floor (prefix SVar names with `floor_`).
- `upgrades.json`: the pool card upgrades are drawn from (power/toughness and keywords).
- `rare_upgrades.json`: the stronger pool offered for the Commander between floors. Besides power/toughness and keywords, an entry can have a `name` (shown instead of the generated text), `costChange` (generic mana, negative is cheaper) and `abilities` (card script lines: `T:`, `S:`, `K:` and `SVar:`; prefix SVar names with `rare_`).
- `starters/`: characters (commander, landless starter deck, Base, reward pool).
  A character's `core` (in `characters/`) must appear 2x in each of its starters, except a starter with `"independentOfCore": true`, which must contain none of it.
- `encounters/`: enemies, Elites and bosses (deck, optional commander, Base, life, hand size, `tier` 1 to 3 for the map's difficulty ladder). `"elite": true` marks an Elite: it needs a commander and ignores tiers. `"interloper": true` marks an encounter met only through a fight event: never on the map, 60 cards with a commander, and it may use cards outside the card scope.
- `events/`: events for Event nodes: a title, scene text, a `kind` (gold, upgrade, card, relicForLife, sellRetry, fight; see `EventDef.java`) and its numbers, plus a `weight`. A `fight` event names an `encounterList` from `config.json`'s `encounterLists` and rolls its opponent from it.
- `cards/`: the mode's own cards (card scripts), added to the card database when the content loads. List them in `cardScopeExceptions` in `config.json`.
- `tokens/`: the mode's own token scripts. A Base or card uses one with `TokenScript$ <file name>`.
- `relics/`: relics. `"eventOnly": true` keeps a relic out of shops and boss rewards (only an event gives it). `"rare": true` makes a rare relic: offered by bosses like any other, elsewhere only at `rareRelicChance` in `config.json`. `script` lines are added to the player's Base each match; prefix SVar names with the relic id.
- `pools/`: card lists. `"bucket": true` makes a themed bucket that can be offered as a reward.
  A bucket is offered only if its cards' colour identity is within the run's colours, except for an occasional "(splash)" slot (`offColourBucketChance` in `config.json`).
  A bucket with `"fromSet": "<set code>"` instead offers cards of that set within the run's colours (its `cards` list is ignored).
- `bases/`: Base card scripts (type line `Types:Base`). Abilities used from the command zone need
  `ActivationZone$ Command`, triggers `TriggerZones$ Command`, statics `EffectZone$ Command`.
- `overrides/`: landless versions of cards that search for lands (ramp, land searches; landcycling becomes cycling),
  used instead of the printed card in every match of the mode and shown in the mode's card previews.
- `quarantine.txt`: cards that can never work without lands, kept out of every deck, pool and the Full Pool.
  Generated by `design/roguelike-run-mode/tools/landless_audit.py`; a card with an override is not quarantined.
- `characters/`: meta-progression per character: commander, starters available from level 1, unlocks by level, milestones (a counter name, a target and unlocks).
- `meta.json`: experience curves and account levels. Relics and pools marked `"locked": true` appear only once an account level unlocks them.
